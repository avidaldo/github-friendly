# Pedir la licencia educativa de GitHub

GitHub ofrece ventajas gratuitas al profesorado en activo a través de **GitHub Education**. Te recomendamos pedirlas aunque al principio no las necesites.

## Qué te da

- **GitHub Copilot Pro**, el asistente de IA de GitHub. Es el que usa la ventana Agents de VS Code.
- **GitHub Team** para una organización: proyectos privados con web publicada y miembros ilimitados. Solo sirve si trabajáis en una [organización](organizacion.md); con tu cuenta personal no cambia nada.

## Qué necesitas

- Una cuenta personal de GitHub.
- Ser docente en activo en un centro educativo.
- Un correo del centro, del que GitHub pueda comprobar que es tuyo.
- Un documento que demuestre que trabajas en el centro, por ejemplo un certificado de servicios o tu nombramiento.

## Cómo pedirla

1. Inicia sesión en GitHub y entra en [github.com/settings/education/benefits](https://github.com/settings/education/benefits).
2. En el apartado **GitHub Education**, pulsa **Start an application** («Empezar una solicitud»).
3. Indica que eres docente, rellena el formulario con los datos de tu centro y sube el documento.
4. Pulsa **Submit application** («Enviar solicitud»).

GitHub revisa la solicitud y te avisa por correo. Si la rechaza, puedes corregir los datos y volver a pedirla. Cuando te la aprueben, tus ventajas aparecen en [github.com/education](https://github.com/education).
