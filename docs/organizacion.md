# Más adelante: trabajar en una organización

El kit está pensado para empezar con **cuentas personales**: una persona crea el proyecto e invita a las demás. Cuando el equipo crece o el proyecto se vuelve importante, puede compensar pasarlo a una **organización**: una cuenta compartida de GitHub a la que pertenecen varias personas, por ejemplo la de un departamento.

## Cuándo compensa

- **Cuando el proyecto no debe depender de una persona.** En una cuenta personal, solo quien creó el proyecto puede cambiar sus ajustes o invitar a otras personas. Si cambia de centro, el proyecto se queda con ella.
- **Cuando necesitáis un proyecto privado.** Con el plan GitHub Team, que el profesorado verificado puede conseguir gratis con la [licencia educativa](licencia-educativa.md), una organización puede tener proyectos privados con web publicada. La web sigue siendo pública.

## Qué cambia

- **Hay que administrar la organización:** alguien decide quién entra y con qué permisos.
- **El proyecto se puede trasladar** de una cuenta personal a una organización sin perder nada: GitHub lo permite desde los ajustes del proyecto.
- **El kit no automatiza todavía las organizaciones.** Las rutinas del día a día (empezar, guardar, publicar) funcionan igual, pero las invitaciones y los permisos se gestionan desde la organización.

Si estáis pensando en dar este paso, consultad con quien mantiene el kit.
