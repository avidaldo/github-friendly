# Frases que entiende tu asistente

No hace falta decirlas exactamente así: tu asistente entiende frases parecidas. Estas son las más útiles.

| Dile | Para |
|---|---|
| «Empiezo» | Ponerte al día antes de trabajar |
| «¿Qué hay de nuevo?» | Saber qué han cambiado los demás |
| «Crea una web nueva sobre…» | Empezar una web en su propia carpeta |
| «Guarda» | Dejar tu trabajo a salvo en tu borrador, sin publicarlo |
| «Publica» | Que tus cambios se vean en la web |
| «Me sale un conflicto» | Resolver un choque entre tus cambios y los de otra persona |
| «Invita a…» seguido de su usuario de GitHub | Que otra persona trabaje en el proyecto (solo quien lo creó) |
| «¿Cuál es la dirección de la web?» | Conseguir el enlace para compartirlo |
| «Actualiza el kit» | Instalar la última versión del kit en el proyecto |

Algunos consejos:

- **Di «empiezo» al abrir el proyecto**, aunque vayas a hacer algo pequeño. Si se te olvida, tu asistente debería hacerlo por su cuenta antes del primer cambio.
- **Pide cambios pequeños y de un solo tema.** Es más fácil revisarlos y, si algo sale mal, deshacerlos.
- **Si no entiendes algo, pregúntale** «¿qué significa eso?» o «explícamelo más sencillo».
