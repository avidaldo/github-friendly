# ¿Público o privado?

## Lo normal: proyectos públicos

Con una cuenta gratuita de GitHub, **solo se pueden publicar webs desde proyectos públicos**. Por eso el kit crea los proyectos como públicos.

Que el proyecto sea público significa que cualquiera puede ver sus archivos en GitHub y también su **historial**: todas las versiones anteriores de cada archivo. Si algo se sube por error y luego se borra, sigue en el historial.

Por eso hay una regla que no tiene excepciones: **nunca subas datos personales del alumnado** (listas con nombres y notas, correos, teléfonos, fotos) **ni contraseñas**. Tu asistente revisa lo que vas a guardar y te avisará si ve algo así, pero la responsabilidad final es tuya.

## Si necesitas un proyecto privado

Hay dos caminos, y en los dos **la web publicada sigue siendo pública**: lo único que queda oculto son los archivos y el historial del proyecto en GitHub.

- **Una cuenta personal de pago (GitHub Pro).**
- **Una organización de GitHub con el plan GitHub Team.** Una organización es una cuenta compartida a la que pertenecen varias personas. Los docentes verificados pueden conseguir GitHub Team gratis con la [licencia educativa](licencia-educativa.md). Más información en [Trabajar en una organización](organizacion.md).

La licencia educativa **no** incluye GitHub Pro para tu cuenta personal: con una cuenta personal, aunque tengas la licencia, los proyectos con web tienen que ser públicos.
